Village Life Open World v3 — Mobile test build

NEW IN v3
- Farming cycle: tractor se field prepare, beej sow, water, harvest.
- Harvest se in-game money milta hai.
- Village shop: seeds and animal feed purchase.
- Cow and buffalo props with feed interaction and reward.
- HUD shows day, money, seed stock and feed stock.
- Existing vehicles, target practice and tractor towing retained.

HOW TO UPDATE
1. Extract this ZIP.
2. Open your existing GitHub repository: village-life.
3. Replace the old index.html with this new index.html.
4. Commit changes and wait for GitHub Pages deployment.
5. Open https://karthikthakur999.github.io/village-life/ and refresh.

NOTE
This remains a lightweight 3D browser prototype, not a full commercial open-world game.
Three.js is loaded from CDN, so internet is required.
