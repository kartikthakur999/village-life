Update your GitHub Pages site:
1. Extract this ZIP.
2. In the village-life repository, upload the new index.html and replace the existing one.
3. Commit changes.
4. Open the game URL and refresh after deployment.

This is still a stylized low-poly browser game prototype, not photorealistic graphics or a finished commercial game. Three.js is loaded from CDN and needs internet.
