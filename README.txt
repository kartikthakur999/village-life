Village Life Open World v1 - मोबाइल वेब गेम टेस्ट

फीचर: 24 घर, गाँव की सड़क, दूर शहर की skyline, खेत, पेड़ों का जंगल, तालाब, गन्ने का छोटा patch, 3 ट्रैक्टर, SUV/Thar-style गाड़ी और बाइक, पैदल/वाहन कंट्रोल, खेत की बेसिक जुताई, पास के ट्रैक्टर को टो करने का शुरुआती सिस्टम।

सीमाएँ: यह अभी एक शुरुआती 3D prototype है, पूर्ण यथार्थवादी गेम नहीं। असली licensed Massey Ferguson/Thar/Fortuner मॉडल/लोगो नहीं हैं; केवल generic tractor/SUV रूप हैं। अभी गियर-क्लच, असली मशीन attachments, बोरिंग/कुआँ, पेड़ काटना, फसल चक्र/गन्ना कटाई, वास्तविक mud physics, multi-tractor rope physics, save game, NPC/animals, audio और विस्तृत नक्शा शामिल नहीं हैं। Three.js CDN के लिए इंटरनेट चाहिए।

GitHub Pages पर अलग repository में रखें। पुरानी repository की index.html को बदलना हो तो पहले backup रखें। ZIP extract करके index.html अपलोड करें। मोबाइल Chrome में साइट खोलें।
